
# Password recovery

Student and admin logins offer Forgot password? ? registered email ? emailed six-digit code ? new password and confirmation ? normal login. The same configured SMTP sender delivers reset codes and a password-change notification. No password is emailed. Existing passwords remain unchanged until a valid code is supplied; all sessions for the account are revoked on success. No automatic login occurs after reset.

Codes are cryptographically random, stored as purpose-separated HMAC-SHA-256 digests using a stable 32-byte `RETURNO_CODE_PEPPER`, single-use, valid for 10 minutes and limited to five attempts. Local startup creates `data/verification-code.key` if no pepper is configured; hosted deployments should supply a stable secret. Requests are throttled per IP; resends are limited to one per minute per account. Request responses are identical for unknown/student/admin emails, and SMTP runs outside the response path. Failed delivery invalidates the associated challenge, logs a generic error without credentials or codes, and leaves the password unchanged. If no email arrives, check spam and contact the administrator.

Recovery requests have the same response for unknown addresses and either account role. A reset challenge is bound to the account's current role and password hash and cannot survive another password change, a role change or account deletion. Password update, challenge consumption and session revocation commit together or roll back together. Migration 5 adds private recovery storage; it is excluded from API projections and cascades on account deletion. The local administrator recovery CLI remains available to operators.

Rotating the pepper invalidates active reset challenges. Legacy reset hashes created before keyed digests are deleted when submitted; request a fresh code afterward. Automated tests use isolated databases, a test-only pepper, and an in-memory email transport. Real Gmail receipt still needs a user inbox check. See [OWASP Forgot Password guidance](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html).
