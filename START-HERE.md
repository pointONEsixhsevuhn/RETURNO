# Start RETURNO

## Windows

1. Open this project folder (extract it from the ZIP first, if needed).
2. If this is the first run, open PowerShell in this folder and run `npm.cmd install` once.
3. Double-click **`start.cmd`** in this folder. Keep its black window open while using RETURNO.
4. The browser opens automatically. If it does not, open the local address printed in that window, usually `http://localhost:3000`.

RETURNO needs Node.js 24 or newer. Do not open `public/index.html` directly or use VS Code Live Server; the app and backend run together through `start.cmd`.

To stop RETURNO, close the black window or press `Ctrl+C` in it.

## Other systems

Install Node.js 24 or newer, open a terminal in this folder, run `npm install` once, then run `npm start`. Keep the terminal open and visit the address it prints.
